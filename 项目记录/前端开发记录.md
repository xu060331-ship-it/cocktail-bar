## 二、技术选型与架构思路

### 2.1 为什么选 React + Vite（而不是 Next.js）

| 考虑因素 | 决策 |
|----------|------|
| 纯前端 SPA，不需要 SSR | Vite 足够，Next.js 过重 |
| 学习曲线 | React 是前端基本功，先学好基础 |
| 部署简单 | Vercel 一键部署 SPA，不需要 Node 服务器 |
| 后续扩展 | 以后可以迁移到 Next.js，组件可复用 |

### 2.7 API 请求封装

```js
// frontend-react/src/lib/api.js
const API_URL = import.meta.env.VITE_API_URL || "http://localhost:3000"

export async function fetchAPI(path, opts = {}) {
  const res = await fetch(`${API_URL}${path}`, {
    method: opts.method || "GET",
    headers: opts.headers || { "Content-Type": "application/json" },
    body: opts.body ? JSON.stringify(opts.body) : undefined,
  })
  if (!res.ok) throw new Error(`API error: ${res.status}`)
  return res.json()
}
```

**设计思路**：
- 所有页面只写 `fetchAPI("/api/xxx")` 不写完整 URL
- 通过 `VITE_API_URL` 环境变量切换本地/线上
- 本地 `.env` → `localhost:3000`，Vercel 环境变量 → Render URL
- 统一错误处理，所有页面 `.catch` 捕获

### 2.9 动画策略（Framer Motion）

| 场景 | API | 应用 |
|------|-----|------|
| 页面入场 | `initial` + `animate` | 所有页面的标题/卡片渐入 |
| 视口触发 | `whileInView` | 首页各屏滚动触发 |
| 元素切换 | `AnimatePresence` + `exit` | 筛选结果变化、问题切换 |
| 悬浮反馈 | `whileHover` + `whileTap` | 卡片、按钮交互 |
| 布局动画 | `motion.div layout` | 卡片网格筛选过滤 |
| 列表交错 | `stagger` + `delay` | 多卡片依次出现 |

### 新学知识点（前端）

**JWT 认证流程：**
- 登录/注册后后端返回 JWT → 前端存 `localStorage.setItem("token", ...)`
- 后续请求在 headers 带 `Authorization: Bearer <token>`
- 页面刷新时读取 token → 调 `/api/auth/me` 恢复用户状态
- 退出时 `localStorage.removeItem("token")` + `setUser(null)`

**React Context 模式（AuthContext）：**
```jsx
// 1. createContext
const AuthContext = createContext(null)
// 2. Provider 包裹整个应用
<AuthContext.Provider value={{ user, login, register, logout }}>
  {children}
</AuthContext.Provider>
// 3. 任意组件消费
const { user, login } = useAuth()
```

**弹窗组件设计模式（AuthModal）：**
- `open` + `onClose` props 控制显示
- `initialMode` prop 决定初始状态（登录/注册）
- `AnimatePresence` 包裹实现进出动画

### 5.1 筛选页面三态分离

```js
const [data, setData] = useState([])

```

```js
const filtered = useMemo(() => {

    if (activeSpirit !== "全部" && c.spirit !== activeSpirit) return false
    if (activeTaste !== "全部" && !c.taste_tags?.includes(activeTaste)) return false
    // ...更多条件
    return true
  })
}, [allCocktails, activeCat, activeSpirit, activeTaste, /* 所有依赖 */])
```
