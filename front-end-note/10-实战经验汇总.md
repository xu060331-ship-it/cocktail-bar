## 2. 你踩过并解决的所有坑

### HTML 坑

| 坑 | 表现 | 原因 | 教训 |
|----|------|------|------|
| `id` 重复 | CSS/JS 只对第一个生效 | 一个页面同一个 id 只能用一次 | 同类元素用 `class` |
| 标签没闭合 | 整个布局塌了 | `<div class="cfc-img">` 缺 `</div>` | 写完一个 div 立刻写闭合 |
| 图片 `"` 没写 | 图片不显示 | `src="./img.png alt=` 浏览器把 `alt=` 也当路径 | 属性的引号要有始有终 |
| `class` vs `id` 选择器不匹配 | CSS 不生效 | HTML 写 `id="btn"`，CSS 写 `.btn` | 对好：`#`=id，`.`=class |

### CSS 坑

| 坑 | 表现 | 原因 | 教训 |
|----|------|------|------|
| 拼写错误 | 样式不生效 | `font-weight: blod` / `18opx` | 怀疑样式不生效时，先检查拼写 |
| `min-height: 100vh` 底部没推下去 | 底部贴在搜索框下面 | 缺 `margin-top: auto` | Flex 列布局 + `margin-top: auto` = 推到底 |
| Grid 4列塌成1列 | 四张卡片叠在一起 | `.section-container` 宽度为0 | 给容器 `width: 100%` |
| 浏览器缓存 | 改了 CSS 没变化 | 浏览器用了旧缓存 | `Ctrl + Shift + R` 强制刷新 |
| 文件没保存 | 改了 VS Code，浏览器不更新 | 文件名旁边有白点 | 先 `Ctrl + S` 再刷新 |

### JS 坑

| 坑 | 表现 | 原因 | 教训 |
|----|------|------|------|
| `<script>` 放 `<head>` | `querySelector` 返回 null | JS 运行时元素还没加载 | `<script>` 放 `</body>` 前 |

### React / 工具坑

| 坑 | 表现 | 原因 | 教训 |
|----|------|------|------|
| 想用 `npx create-react-app` 再建项目 | 又下载几百 MB，跟已有项目无关 | CRA 是另一个工具链，Vite 已替代它 | 只用 Vite：`npm create vite@latest` |
| 以为每开一次电脑就要 `npm install` | 白等一分钟 | 依赖只需装一次，存 `node_modules/` 里 | 日常开发只要 `npm run dev` |
| JSX 里 `class` 没写 `className` | 编译报错 | React 用 `className` | JSX ≠ HTML |
| Vite 报错 "module not found" | 页面白屏 | 组件路径写错了 | 检查 `import` 路径 |
| 端口被占用 | `localhost:5173` 打不开 | 上次 Vite 没关 | 关掉终端重新 `npm run dev` |

## 3. 调试流程（遇到问题按这个顺序来）

```
1. Ctrl + S           ← 确认保存
2. Ctrl + Shift + R   ← 强制刷新浏览器
3. F12 → Console      ← 看有没有红色报错
4. F12 → Elements     ← 用箭头选元素，看 Styles 面板
5. 加临时红色边框     ← body { border: 10px solid red } 确认 CSS 是否加载
6. 检查拼写          ← 属性名、选择器、变量名一个一个对
7. 问 AI             ← 描述"我预期 X，实际 Y，代码是 Z"
```

## 5. 重要习惯

| 习惯 | 为什么 |
|------|--------|
| 每做一个小功能就保存 + 刷新看效果 | 攒到 100 行再刷，报错找不到是哪行 |
| 手敲代码，不复制粘贴 | 肌肉记忆比理解记忆持久 |
| DevTools 一直开着 | 第一时间看到报错 |
| 命名用英文 | `nav-left` 比 `zuobian-lan` 规范 |
| HTML 写标签的同时写闭合 | `<div>` 写完立刻 `</div>`，不然后面忘了 |
| 怀疑什么都不对的时候，先怀疑自己没保存 | 90% 的"CSS 不生效"是因为没保存或被缓存了 |
