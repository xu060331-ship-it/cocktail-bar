# 09 - 工具链与项目结构

> 现代前端开发的"生产线"是怎么搭起来的。

---

## 1. Node.js 与 npm

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **Node.js** | 让电脑能脱离浏览器运行 JS | Java 的 JVM |
| **npm** | Node 的包管理器 | 手机应用商店 |
| `package.json` | 记录项目信息和依赖 | 购物清单 |
| `node_modules/` | 装包的地方 | 下载的 App 本体 |
| `npm install` | 按 package.json 装所有依赖 | 一键安装购物清单里的全部东西 |

---

## 2. 常用 npm 命令

```bash
npm create vite@latest            # 创建新项目（用 Vite 模板）
npm install                        # 安装 package.json 里的所有依赖
npm install 包名                   # 安装一个新包
npm install -D 包名                # 安装到开发依赖（构建工具类）
npm run dev                        # 启动开发服务器
npm run build                      # 构建生产版本
```

## 3. Vite — 开发服务器 + 打包器

### 🔴 Vite vs create-react-app（CRA）

| | Vite | create-react-app |
|---|------|-----------------|
| React 官方态度 | ✅ 推荐 | ❌ 已从文档中移除 |
| 启动速度 | 几百毫秒（你的项目 817ms） | 几十秒 |
| 社区 | 当前主流 | 基本不维护了 |
| 你现在 | ✅ 已学会 | ❌ 不需要用 |

> 以后新建任何 React 项目，**只用 Vite，不用 CRA。**

### 🔴 新项目一次性搭建（6 条命令 + 改 2 个文件）

**只在项目第一天做一次：**

```bash
# ① 创建项目
npm create vite@latest 项目名 -- --template react
cd 项目名

# ② 装基础依赖
npm install

# ③ 装你常用的四件套
npm install tailwindcss @tailwindcss/vite framer-motion lucide-react
```

**④ 改 `vite.config.js`**（告诉 Vite"我装了 Tailwind，请帮我处理 CSS"）：

```js
import tailwindcss from '@tailwindcss/vite'        // ← 加在文件顶部

export default defineConfig({
  plugins: [react(), tailwindcss()],                // ← plugins 数组里加上 tailwindcss()
})
```

**⑤ 改 `src/index.css`**（引入 Tailwind + 定义你自己的颜色变量）：

```css
@import "tailwindcss";

@theme {
  --color-accent: #c9a96e;
  /* 你的颜色变量 */
}
```

```bash
# ⑥ 启动开发
npm run dev        # 打开 http://localhost:5173
```

### 🔴 日常开发（每天写代码只需要一行）

```bash
cd 你的项目文件夹
npm run dev
```

**不需要重新 npm install，不需要重新改配置文件。** 依赖只在第一天装一次。

Vite 做的事：
- 启动一个本地 Web 服务器
- 代码改了**热更新（HMR）**——浏览器自动刷新，不用手动 F5
- 构建时把所有文件打包压缩

## 4. 项目文件结构（你当前项目）

```
frontend-react/
├── index.html                 ← 入口 HTML（Vite 生成，不用改）
├── package.json               ← 项目配置 + 依赖清单

        ├── ClassicCocktails.jsx ← 经典鸡尾酒
        └── BaseSpirits.jsx    ← 六大基酒
```

## 5. 你的 package.json 依赖

```json
{
  "dependencies": {
    "react": "^19.x",
    "react-dom": "^19.x",
    "framer-motion": "^12.x",
    "lucide-react": "^0.x"
  },
  "devDependencies": {
    "@vitejs/plugin-react": "^4.x",
    "vite": "^6.x",
    "tailwindcss": "^4.x",
    "@tailwindcss/vite": "^4.x"
  }
}
```

| 包 | 干什么 | 类型 |
|----|--------|------|
| `react` | React 核心 | 运行时依赖 |
| `react-dom` | React 渲染到 DOM | 运行时依赖 |
| `framer-motion` | 动画库 | 运行时依赖 |
| `lucide-react` | 图标库 | 运行时依赖 |
| `vite` | 构建工具 | 开发依赖 |
| `@vitejs/plugin-react` | Vite 的 React 插件 | 开发依赖 |
| `tailwindcss` | CSS 框架 | 开发依赖 |
| `@tailwindcss/vite` | Tailwind v4 的 Vite 插件 | 开发依赖 |

> 运行时 vs 开发依赖：用户浏览器只加载运行时依赖。构建工具只在开发时用。

## 6. 生命周期四阶段

```
1. 下载模板
   npm create vite@latest
   ↓
2. 装依赖
   npm install
   ↓
3. 开发
   npm run dev      → localhost:5173，热更新
   ↓
4. 上线
   npm run build    → dist/ 文件夹，部署到服务器
```

## 7. public/ vs src/

| 文件夹 | 放什么 | 怎么引用 |
|--------|--------|---------|
| `public/` | 视频、字体、favicon | `<source src="/hero-bg.mp4">`（`/` 开头） |
| `src/assets/` | 组件内的图片 | `import img from './assets/xxx.png'` |

> 简单判断：全站公共的静态文件放 `public/`，跟组件绑定的图片放 `src/assets/`。

## 8. 浏览器 DevTools 你还应该知道的

| 面板 | 快捷键 | 用在哪 |
|------|--------|--------|
| **Elements** | `F12` → Elements 标签 | 看 HTML 结构 + 实时改 CSS |
| **Console** | `F12` → Console 标签 | 看 JS 报错信息 |
| **Network** | `F12` → Network 标签 | 看文件加载速度、API 请求 |
| **Application** | `F12` → Application 标签 | 看 Local Storage / Cookies |
| 选择元素箭头 | `Ctrl + Shift + C` | 点页面上的东西直接跳到对应的 HTML |

> 🔴 **最重要的调试习惯：** 遇到样式问题，先 `F12` → 点箭头 → 点那个元素 → 看 Styles 面板。被划掉的样式就是被覆盖掉了。
