## 一、React 组件化

### 1.1 组件创建与导出

```jsx
// 函数组件 — 本项目所有组件都是这种形式
export default function ComponentName() {
  return <div>...</div>
}
```

| 知识点 | 出现在哪些文件 | 作用 |
|--------|-------------|------|
| `export default` | 所有 6 个组件 + 5 个页面 | 导出组件供其他文件 import |
| 函数组件 | 全部 `.jsx` 文件 | React 组件的基本形态 |
| 组件文件命名 | `Navbar.jsx`, `HeroSection.jsx`... | PascalCase 命名，见名知义 |

### 1.2 组件组合（Composition）

```jsx
// App.jsx — 父组件组装子组件
<BrowserRouter>
  <Routes>
    <Route element={<Layout />}>
      <Route path="/" element={<HomePage />} />
      ...
    </Route>
  </Routes>
</BrowserRouter>
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| 父子组件嵌套 | `App.jsx` → `Layout` → `HomePage` | 三层嵌套：路由 → 布局 → 页面 |
| `Outlet` | `App.jsx` | 子路由内容渲染到 Layout 的指定位置 |
| 组件复用 | `Navbar.jsx` | 所有页面共用一个导航栏 |

### 1.3 JSX 语法

| JSX 规则 | 示例 | 出现的文件 |
|---------|------|-----------|
| `className` 代替 `class` | `className="flex items-center"` | 所有文件 |
| `{}` 嵌入 JS 表达式 | `{c.name}`, `{active === i ? "选中" : "默认"}` | 所有文件 |
| 自闭合标签 | `<img src="..." />`, `<ArrowRight />` | 详情页、图标 |
| 注释 | `{/* 这是注释 */}` | 所有文件 |

### 1.4 Props（父子组件传值）

```jsx
// 父组件传值
<Navbar transparent={isHome} />

// 子组件接收
export default function Navbar({ transparent = false }) { ... }
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| Props 传递 | `App.jsx` → `Navbar.jsx` | `transparent` 控制导航栏透明/实色 |
| 默认值 | `{ transparent = false }` | 不传时用默认值 |
| Props 解构 | `{ q, a, index }` | `WhiskyQA.jsx` — QACard 组件 |

### 1.5 列表渲染（.map()）

```jsx
{cocktails.map((c, i) => (
  <motion.div key={c.eng} custom={i}>
    <h3>{c.name}</h3>
```

| 知识点 | 文件 | 作用 |

| 单层 `.map()` | `BaseSpirits.jsx` | 6 种基酒 → 6 张卡片 |

## 二、React Router（前端路由）

### 2.1 路由配置

```jsx
<BrowserRouter>
  <Routes>
    <Route element={<Layout />}>
      <Route path="/" element={<HomePage />} />
      <Route path="/cocktails" element={<CocktailsPage />} />
      <Route path="/cocktails/:name" element={<CocktailDetailPage />} />
    </Route>
  </Routes>
</BrowserRouter>
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| `BrowserRouter` | `App.jsx` | 启用前端路由 |
| `Routes` + `Route` | `App.jsx` | URL 匹配 → 渲染对应页面 |
| 动态路由 `:name` | `App.jsx` | `/cocktails/Singapore%20Sling` 匹配到详情页 |
| `Outlet` | `App.jsx` Layout | 子路由渲染出口 |
| `useLocation` | `Navbar.jsx` | 读取当前 URL → 高亮导航 + 判断是否透明 |
| `useParams` | `CocktailDetailPage.jsx` | 读取 URL 里的 `:name` 参数 |
| `Link` | `Navbar.jsx`, `CocktailsPage.jsx` | React 版 `<a>`——不刷新页面 |
| `<a>` vs `<Link>` | 全部导航 | `<Link>` = 站内不刷新；`<a>` = 外部链接 |

### 2.2 导航高亮

```jsx
const location = useLocation()
const isActive = location.pathname === link.to
className={isActive ? "text-accent" : "text-gray"}
```

| 文件 | 知识点 |
|------|--------|
| `Navbar.jsx` | `useLocation` + 条件样式 = 当前页高亮 |
| `App.jsx` | `useLocation` → 首页透明 / 其他页实色导航 |

## 三、React Hooks

### 3.1 useState — 状态管理

| 文件 | 状态变量 | 用途 |
|------|---------|------|
| `WhiskyQA.jsx` | `const [active, setActive] = useState(0)` | 记录选中的问题索引 |
| `BaseSpirits.jsx` | `const [hovered, setHovered] = useState(null)` | 记录当前悬停的卡片 |
| `CocktailsPage.jsx` | `const [search, setSearch] = useState("")` | 搜索框输入内容 |
| `CocktailsPage.jsx` | `const [activeCat, setActiveCat] = useState("全部")` | 分类筛选 |
| `CocktailsPage.jsx` | `const [activeSpirit, setActiveSpirit] = useState("全部")` | 基酒筛选 |
| `SpiritsPage.jsx` | `const [showSeventh, setShowSeventh] = useState(false)` | 第七大基酒展开/折叠 |
| `ArticlesPage.jsx` | `const [hoveredArticle, setHoveredArticle] = useState(null)` | 悬停高亮 |

### 3.2 useState 关键理解

| 知识点 | 示例 | 说明 |
|--------|------|------|
| 状态不可直接改 | `setActive(1)` 而不是 `active = 1` | 必须用 setter，React 才会重新渲染 |
| 状态异步更新 | `setOpen(!open)` | 取反切换 |
| 初始值类型 | `useState(0)`, `useState("")`, `useState(null)`, `useState(false)` | 数字、字符串、null、布尔 |

### 3.3 useMemo — 缓存计算

```jsx
const filtered = useMemo(() => {
  return allCocktails.filter((c) => {
    if (activeCat !== "全部" && c.cat !== activeCat) return false
    if (search && !c.chnClean.includes(search)) return false
    return true
  })
}, [activeCat, activeSpirit, search])
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| `useMemo(fn, deps)` | `CocktailsPage.jsx` | 依赖项不变就不重新计算 |
| 依赖数组 | `[activeCat, activeSpirit, search]` | 这三个变了才重新筛选 |
| `DailyPage.jsx` | `useMemo` | 日期不变就不重新随机 |

### 3.4 受控组件（Controlled Input）

```jsx
<input
  value={search}
  onChange={(e) => setSearch(e.target.value)}
/>
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| `value` + `onChange` | `CocktailsPage.jsx` | React 控制输入框的值 |
| `e.target.value` | `CocktailsPage.jsx` | 读取用户输入内容 |
| 实时搜索 | `CocktailsPage.jsx` | 输入即搜索，不用点按钮 |

## 五、Framer Motion

### 5.1 五种核心动画模式

| 模式 | 代码 | 本项目使用位置 |
|------|------|-------------|
| 进场动画 | `initial={{ opacity: 0 }} animate={{ opacity: 1 }}` | Hero 文字逐个浮现 |
| 滚到才播 | `whileInView={{ opacity: 1, y: 0 }}` | 所有区块标题、卡片 |
| 悬停 | `whileHover={{ y: -8 }}` | 全部卡片 |
| 点击 | `whileTap={{ scale: 0.97 }}` | Hero 按钮 |
| 离开 | `AnimatePresence` + `exit` | QA 答案展开/收起、筛选动画 |

### 5.2 交错动画（Stagger）

```jsx
const variants = {
  hidden: { opacity: 0, y: 48 },
  visible: (i) => ({
    opacity: 1, y: 0,
    transition: { duration: 0.9, delay: i * 0.15 }
  }),
}

// 第 0 张：delay 0s，第 1 张：delay 0.15s，第 2 张：delay 0.30s...
```

| 文件 | 交错延迟 | 效果 |
|------|---------|------|
| `ClassicCocktails.jsx` | `i * 0.15` | 4 张卡片依次浮出 |
| `BaseSpirits.jsx` | `i * 0.08` | 6 张卡片依次浮出 |
| `WhiskyQA.jsx` | `i * 0.1` | 3 个问题依次出现 |
| `SpiritsPage.jsx` | `i * 0.08` | 6 张大卡依次出现 |
| `ArticlesPage.jsx` | `i * 0.06` | 文章列表依次出现 |

### 5.3 动态 animate（聚光灯效果）

```jsx
// BaseSpirits.jsx — 悬停一张，其余暗淡模糊
animate={{
  scale: isHovered ? 1.04 : 1,
  opacity: isHovered === null ? 1 : isHovered ? 1 : 0.4,
  filter: isHovered === null ? "blur(0px)" : isHovered ? "blur(0px)" : "blur(1.5px)",
}}
```

| 知识点 | 说明 |
|--------|------|
| `animate` 接受动态值 | 根据状态变量改变动画目标 |
| `filter: blur()` | GPU 加速模糊，制造景深效果 |
| `pointer-events-none` | 装饰元素不阻挡鼠标 |

### 5.4 AnimatePresence

| 文件 | 用途 |
|------|------|
| `WhiskyQA.jsx` | 答案区切换动画：旧内容左滑消失，新内容右滑进入 |
| `CocktailsPage.jsx` | 筛选后卡片平滑消失/出现 |
| `SpiritsPage.jsx` | 第七大基酒展开/折叠 |

```jsx
<AnimatePresence mode="wait">   {/* mode="wait" = 旧动画播完再播新的 */}
  <motion.div key={active} exit={{ opacity: 0, x: -30 }}>
    ...
  </motion.div>
</AnimatePresence>
```

### 5.5 动画参数调优经验

| 参数 | 本项目取值 | 经验 |
|------|----------|------|
| `duration` | 大动画 `0.7-0.9s`，微交互 `0.3-0.5s` | 慢 = 沉稳高级；快 = 轻巧反馈 |
| `ease` | `[0.16, 1, 0.3, 1]` | 快出慢停，有弹力不夸张 |
| `delay` | 首个 `0`，后续 `i * 0.08 ~ 0.15` | 太密像弹窗，太疏等得急 |
| `amount: 0.3` | 元素露出 30% 触发 | 太低卡一半就触发了，太高等不到 |

### 7.4 伪随机算法

```jsx
function seededRandom(seed) {
  let h = 0
  for (let i = 0; i < seed.length; i++) {
    h = ((h << 5) - h + seed.charCodeAt(i)) | 0
  }
  return () => {
    h = (h * 1103515245 + 12345) | 0
    return (h >>> 0) / 0xffffffff
  }
}
```

| 知识点 | 文件 | 作用 |
|--------|------|------|
| 哈希种子 | `DailyPage.jsx` | 同一天生成相同的随机序列 |
| `useMemo` + 日期种子 | `DailyPage.jsx` | 当天内容固定，明天自动换 |

### 8.1 CSS Scroll Snap（全屏吸附）

```css
  height: 100dvh;
  overflow-y: scroll;
  scroll-snap-type: y mandatory;

  scroll-snap-align: start;

```

| 文件 | 用途 |
|------|------|
| `HomePage.jsx` | 5 屏全屏滚动吸附 |

### 8.2 CSS 变量 + 暗色主题

```css
:root {
  --color-bg-page: #12100d;     /* 暖黑底 */
  --color-bg-card: #1c1813;     /* 卡片色 */
  --color-accent: #c9a96e;      /* 琥珀金强调 */
}
```

| 知识点 | 说明 |
|--------|------|
| 暖黑 vs 冷黑 | `#12100d` 带红棕底调，呼应酒吧暖光 |
| 单一 accent | 全站只用 `#c9a96e`，不飘色 |
| 三层灰 | `#fff` → `#c4b8a8` → `#8a8078` 拉开信息层级 |

### 8.3 全局纹理

```css
body::after {
  content: "";
  position: fixed;
  inset: 0;
  z-index: 9999;
  pointer-events: none;
  opacity: 0.04;
  background-image: url("data:image/svg+xml,...");  /* SVG噪点 */
}
```

`feTurbulence` SVG 滤镜生成噪点纹理，0.04 透明度刚好能感觉到但不影响可读性。

### 8.4 `100dvh` vs `100vh`

| 值 | 行为 | 使用位置 |
|----|------|---------|
| `100dvh` | 动态视口高度，移动端地址栏不挤页面 | Hero、所有全屏区块 |
| `100vh` | 静态视口高度，iOS Safari 有 bug | ❌ 本项目不使用 |

## 十一、调试与开发习惯

| 习惯 | 说明 |
|------|------|
| `Ctrl + S` | 先保存再刷新 |
| `Ctrl + Shift + R` | 强制刷新，清除缓存 |
| `F12` → Elements | 实时看 HTML + 改 CSS |
| `F12` → Console | 看 JS 报错 |
| `npm run dev` | 每次开发的唯一启动命令 |
| 手敲代码 | 不复制粘贴，建立肌肉记忆 |
| 写了 `<div>` 立刻写 `</div>` | 避免标签未闭合 |
| 红色边框测试 | `body { border: 10px solid red }` → CSS 加载了没 |
